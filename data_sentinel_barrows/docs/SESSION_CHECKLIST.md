# Pre-Session Checklist

Before starting a new chat session:

[ ] 1. Update CHANGES.md with everything done in last session
[ ] 2. Update compact_context.md Section 10 (Recent Changes)
[ ] 3. Update compact_context.md Section 9 (Open Items)
        - Check off resolved items
        - Add new items discovered
[ ] 4. Identify which single file you are working on today
[ ] 5. Have that file ready to paste
[ ] 6. Have one reference file ready IF building something new

During session:
[ ] Ask for surgical find/replace — never full file rewrites
[ ] Confirm IDs match before applying any change
[ ] Note any new IDs or patterns discovered for compact_context update

After session:
[ ] Update CHANGES.md
[ ] Update compact_context.md
[ ] Commit files to version control if applicable
